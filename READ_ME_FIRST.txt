VEILBOUND - PC EDITION (Beginner Starter)
========================================

You only need a Windows PC and a web browser (Edge or Chrome).
You do NOT need Node.js, Android Studio, or any coding tools.

HOW TO PLAY
1. Right-click the ZIP file and choose Extract All.
2. Open the extracted VEILBOUND_PC folder.
3. Double-click PLAY_VEILBOUND.bat.
4. If Windows asks about running the batch file, you can instead double-click VEILBOUND_GAME.html.
5. The game opens in your default browser. Enjoy!

WHAT IS INCLUDED
- Solo card battles against AI, with faction and difficulty selection
- Card collection and deck builder
- Booster opening using fictional Moonshards
- Illustrated cards and battle effects

SAVING
The game stores progress in your browser on this computer.
Use the game's Export Save option to make a backup.
Opening the file in another browser may show a separate save.

OPTIONAL DESKTOP SHORTCUT
Right-click PLAY_VEILBOUND.bat -> Show more options -> Send to -> Desktop (create shortcut).

IMPORTANT
This is a playable browser-based PC prototype, not a compiled .exe installer.
Some features may need testing in your browser. No internet connection should be needed after downloading.
